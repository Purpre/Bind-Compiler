Bind Programming Language Documentation

Bind is a line-oriented language, where each line must be an instruction.

INSTRUCTIONS

Print and Println:
Println prints a variable, string, or integer to the terminal (string or integer). It includes a line break at the end.
Print performs the same function, but without a line break at the end.

println <content>
print <content>

Let:
Defines a variable, which can be an integer or a text(string).

let <variable_name> = <value>

Let can also be used without defining an initial value. This is useful if you want to store the result of an input in the variable.

let <variable_name> : <type> (string or int)

Set:
Changes the value of a variable. Note that the variable must be declared beforehand and its type cannot be mutated.

set <variable_name> = <value>

Label:
Defines a marker in the code that a goto instruction can jump to.

label <label_name>

Goto:
Jumps the code execution to an existing label.

goto <label_name>

Dynamic Label:
Defines a label that can be changed during code execution. Use bind to define a label that will represent the dy_label.

dy_label <dy_label_name>

Bind:
Defines which conventional label a Dynamic Label will point to.

bind <dy_label_name> -> <label_name>

If:
Compares two numeric values or variables. If the comparison is true, it uses goto to jump to a specific label.

if <value> <comparator> <value> goto <label_name>

Possible comparators:

== Equal to
!= Different from
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to

Add:
Adds two numeric values or variables and stores the result in a variable.

add <value1> <value2> -> <result>   (result = value1 + value2)

Sub:
Subtracts two numeric values or variables and stores the result in a variable.

sub <value1> <value2> -> <result>   (result = value1 - value2)

Clear:
Clears the terminal.

clear

Pause:
Pauses the terminal.

pause

Comments:
Use // to define a comment. Note that the comment symbol (//) must be separated by a space from the comment , and it cannot be placed after a line of code.

// Example of a comment

Color:
Defines a color to use in the print and println functions.

color <desired_color>

Possible colors:

black
red
green
yellow
blue
magenta
cyan
white

Title:
Defines a title for the execution terminal. Note that the title must be a string.

title <desired_title>

Delay:
Pauses code execution for a specified amount of time (in milliseconds).

delay <delay_time_in_milliseconds>

Input:
Pauses code execution and waits for user input. Inserts what the user typed into a string variable.

input -> <variable>



CODE EXAMPLES

Recommended standard code template:

clear
goto main

// FUNCTIONS

label main

// CODE

pause


Simple Function:

clear
goto main

dy_label end_print_hi
label func_print_hi

println "Hi"

goto end_print_hi

label main


// First call of the function

bind end_print_hi -> call1
goto func_print_hi
label call1


// Second call of the function

bind end_print_hi -> call2
goto func_print_hi
label call2

pause
